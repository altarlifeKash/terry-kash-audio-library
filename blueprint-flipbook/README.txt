THE BLUEPRINT — ANIMATED FLIPBOOK PACKAGE

This package is self-contained. It does not depend on a third-party flipbook service or remote JavaScript.

UPLOAD TO YOUR WEBSITE
1. Create a folder on your web hosting, for example /blueprint/.
2. Upload EVERYTHING inside The_Blueprint_Animated_Flipbook into that folder, preserving the pages/ subfolder.
3. Visit that folder's index.html in a browser.

FEATURES
- Animated page turns
- Front cover shown alone on desktop
- Facing-page book spreads on desktop
- Single-page portrait reading on phones/tablets
- Previous/Next buttons
- Clickable page edges
- Keyboard arrow navigation
- Swipe navigation
- Full-screen button
- Included PDF button

LOCAL TEST
For best results, serve the folder through a web server. Example from inside the folder:
python3 -m http.server 8000
Then visit http://localhost:8000
